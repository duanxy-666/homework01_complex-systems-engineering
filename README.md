## 项目简介

本项目围绕“任务 Mission → 体系 SoS → 整机 Vehicles → 系统 Systems → 子系统 Subsystems → 模块 Modules”开展系统架构设计。

完整内容包括：
- 6 个架构层级；
- 8 个系统、24 个子系统、96 个模块；
- 5 条端到端追溯链；
- 18 条需求与验证映射；
- 8 项风险分析；
- 具身智能的感知—规划—动作—反馈闭环，以及人工授权与安全治理。

武装属性仅在任务授权、安全约束和责任审计层作概念性分析，不包含可执行的武器制造、火控、自动攻击或致伤技术。
